# Smart Study Buddy 🤖📚

[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi)](https://fastapi.tiangolo.com)
[![Ollama](https://img.shields.io/badge/Ollama-FFD43B?style=for-the-badge&logo=ollama&logoColor=black)](https://ollama.ai)

An AI-powered study assistant that generates questions and answers from uploaded documents using DeepSeek LLM.

## Key Features ✨
- PDF/TXT document processing
- AI-generated study questions
- Context-aware Q&A system
- Local LLM integration (DeepSeek 1.5B)
- Responsive web interface

## Tech Stack 🛠️
- **Backend**: FastAPI
- **AI**: DeepSeek-1.5B, LangChain, Hugging Face
- **Vector DB**: FAISS
- **Frontend**: Tailwind CSS, JavaScript
